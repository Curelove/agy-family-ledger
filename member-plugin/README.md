# 家庭组额度看板（Antigravity App 侧边栏插件）

用于在熟人共享家庭组内查看 Gemini 4 与 Claude 3P 剩余额度、近 5 小时窗口活跃情况，以及本周期各成员的用量占比。

## 使用前提
- 需要 **Antigravity App**（支持侧边栏 Sidecar 扩展；独立 IDE 版本暂不支持侧边栏）与本机已安装 Node.js。
- 首次复制安装并重启 Antigravity 后，请在扩展管理页面确认「家庭组额度看板（`agy-family-ledger`）」处于启用状态。

## 连接方式
1. 安装并启用插件后，在 Antigravity 右侧边栏打开「家庭组额度看板」。
2. 粘贴组长提供的单行纯文本绑定码（格式如 `https://域名#agf_xxxx&v=1&m=board&g=100&p=180`），点击「连接看板」即可。
3. 绑定码中锁定了入组时的计费规则；后续若组长调整模式或单价，侧边栏顶部会明确提示差异并需你本人确认后才生效。

## 数据范围
- 只上报本地对话步骤中的纯数字 Token 计数、模型名、时间戳、在线状态心跳，以及 `127.0.0.1` 官方配额摘要百分比（会话 ID 经 SHA-256 短哈希脱敏）。
- 不读取任何工作区代码、对话正文、思考文本、本机运行进程或代理软件配置。
