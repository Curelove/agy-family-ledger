# v1.3.0 · 全组使用约定公示、底线/上限提醒与规则版本锁定

本次更新新增 **全组使用约定** 公示与温和提醒功能，让家庭组成员在各自侧边栏清楚看到共同商定的保留底线与单人参考上限，同时把所有使用约定纳入与计费单价同等级的防暗改版本锁定机制，在默认纯看板模式下也能透明协作。

### 1. 全组使用约定公示（选填，未配置时界面保持精简）
- **总池保留底线**：支持设置周池剩余百分比底线（例如 20%）。设置后，管理控制台与成员侧边栏的 Gemini 4 / Claude 3P 进度条都会标出底线刻度；当任一池子剩余降至底线或以下时，顶部显示温和提醒，建议暂缓非紧急重任务。
- **单人本周期参考上限**：支持按人数设置单人每周期参考上限（设置页提供「总池留 20% 底线」「双人组 · 单人 50%」「三人组 · 单人 30%」「四人组 · 单人 25%」等快捷预设）。当个人本周期用量接近（85%）或达到参考上限时，侧边栏给出温和提示，成员列表附带克制的「已达上限参考」标记。
- **公开标明组长适用范围**：新增「该单人上限对组长本人同样生效」开关（默认开启），并在成员侧边栏如实标示「全员同等适用」或「适用于普通成员」，避免出现规则只约束组员的双标观感。
- **补充约定说明与客观边界声明**：支持附加不超过 180 字的单行补充说明；侧边栏明确提示以上约定仅作全组协作参考，插件不会强行中断使用。

### 2. 防暗改与透明审计延伸至使用约定
- **纳入规则版本号与变更日志**：修改保留底线、单人上限、组长适用范围或补充说明中的任意一项，都会自动递增 `rule_version`、写入全体可见的 `rule_changes` 变更历史，并在纯看板模式下开放「规则变更记录」折叠栏供成员随时查阅。
- **绑定码锁定与成员确认**：绑定码自动附带当前使用约定参数与补充说明短哈希（完全兼容 `v1.1.0` / `v1.2.0` 旧绑定码）；若组长在发出链接后或成员使用期间单方面改动约定，成员侧边栏顶部会立刻弹出新旧约定对比卡片，由成员选择「确认接受新规则」或「暂不接受并断开」。

### 3. 自动化回归验证
- 新增全组使用约定绑定码锁定、纯标准 JS 短指纹跨端一致性、无感暗改拦截、纯看板模式版本递增与底线/上限实时触发等端到端回归测试（13/13 通过），保持 `v1.2.0` 到 `v1.3.0` 零迁移平滑升级。
