# v1.5.0 · 分级强警示卡片、「普通成员仅限 Gemini 池」显式规则与黑洞异常全组公示

本次更新显著提升了成员侧边栏在超限、欠费、误用约定外模型池、被组长暂停及全组异常掉量时的可见度，避免关键提醒被淡色小字淹没。

### 新增与改进
- **分级强警示卡片（红 / 琥珀双色体系）**：
  - 将「**账号已被组长暂停/停用**」「**检测到约定外 Claude 3P 消耗**」「**可用余额已用完/欠费**」「**已超出/达到个人单周期上限**」升级为带醒目警示图标、粗体大标题、高对比红底胶囊标签与左侧红边条的强提醒卡片。
  - 将「**可用余额偏低**」「**即将达到个人上限（85%）**」「**全组共享池触及保留底线**」升级为带图标与粗体标题的琥珀色提醒卡片。
  - 修复账号被组长暂停或凭证停用时套用「同步暂未送达（已暂存本地队列）」普通网络错误前缀的问题，现改为清晰直白的独立状态卡。
- **「普通成员仅限使用 Gemini 池（禁用 Claude 3P）」显式开关**：
  - 组长可在本地管理台「**设置 → 全组使用约定**」开启该开关（自动纳入规则版本锁定与防暗改校验）。
  - 一旦检测到普通成员产生 Claude 3P 调用（即使尚未凑满一次周水位下降），成员侧边栏顶部立即弹出红色「**误用 3P**」强警示卡片并在用量格与成员列表标红，同时自动写入组长管理台的「**异常记录**」。
- **未统计消耗（黑洞）异常全组同步公示开关**：
  - 管理台「**设置**」新增「**向全体成员侧边栏公示未统计消耗（黑洞）异常**」开关（默认开启）。检测到明显未匹配本地插件的掉量异常时，全体组员侧边栏顶部同步展示全组异常提醒以便自查（绝不泄露任何人的私密余额告警），组长标记已读后自动撤下。
- **「已全部同步」状态胶囊与可展开同步详情抽屉**：
  - 将「我本周期的用量」右侧原本偏底层术语的「待传记录 N」升级为语义清晰的可点击状态胶囊（「**已全部同步**」「**正在同步…**」「**待同步 N 条**」「**暂存待补传 N 条**」），并在上传途中自动开启短间隔快刷，消除上传完成后仍停留旧数字长达 30 秒的观感错觉。
  - 点击胶囊可原地展开同步详情抽屉，查看本机暂存队列数、最近成功同步时间、上传目标服务域名、数据来源与去向说明、最近一批已送达（或当前暂存）的模型步骤记录，并支持一键「**立即同步 / 立即补传**」。
- **自动化回归**：新增 3P 禁限即刻检测、黑洞全组隐私公示与已读撤下、暂停态结构化识别及同步队列预览/最近送达摘要端到端回归测试（16/16 通过）。
