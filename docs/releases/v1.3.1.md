# v1.3.1 · 修复高积压记录写入 Cloudflare D1 超时导致的同步卡滞

本次为稳定性热修版本，彻底修复了本地短时间内产生大量对话步骤（例如 100+ 条积压记录）时，服务端逐条串行写入 Cloudflare D1 触发客户端 12 秒超时、导致队列反复重试无法清空的问题。

### 修复内容
- **Cloudflare D1 批量写入（`d1.batch`）**：在存储层 `wrapD1Adapter` 中新增批量执行通道，单次心跳内的增量上报记录改为每 50 条合并为 1 次 D1 批量提交，大批次入库耗时从十余秒降至亚秒级。
- **成员端分批平滑补传与放宽超时**：成员端采集器将单次请求携带上限由 200 条调整为 80 条，请求超时由 12 秒放宽至 25 秒，并在检测到积压队列时自动连续分批补传（单轮最多 4 批），跨国网络波动或 Worker 冷启动下也能稳定清空待传队列。
- **自动化回归**：新增大批量事件批量入库与分批补传端到端回归测试（14/14 通过）。
