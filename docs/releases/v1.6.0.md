# v1.6.0 · 多账号自动识别防串号、双模式归属锁与全链路边界加固

本次更新围绕**多账号切换零混账、零串号水位**以及全链路采集/结算/稳定性边界做了系统性升级，同时保持对尚未升级的 `v1.5.0` 成员端与线上 Cloudflare D1 数据库 100% 无损向后兼容。

### 新增与核心升级
- **多账号实时感知与 6 态采集状态机（12 秒本地零流量守卫）**：
  - Sidecar 通过官方宿主注入的 `127.0.0.1` 回环接口只读查询 `GetUserStatus`，**仅在内存中计算域隔离 SHA-256 短指纹（20 位 hex）与本地脱敏显示串（如 `ali***@example.com`）**，明文完整邮箱绝不落盘、绝不上传，全程零外部子进程、零进程/注册表/凭据扫描。
  - 新增 12 秒本地守卫与 6 态状态机（`UNBOUND` / `ACTIVE_MATCH` / `PAUSED_ACCOUNT_MISMATCH` / `PAUSED_MANUAL` / `PAUSED_IDENTITY_UNAVAILABLE` / `BLOCKED_BY_SERVER`）：切到个人号或未登录时立即停采且持续将活跃日志游标静默快进至文件末尾；切回家庭组账号、从插件禁用停摆间隙恢复或点击「**恢复统计（从此刻起算）**」时，先锚定游标再起算，彻底杜绝翻旧账。
  - 处于「切号自动暂停」或「手动暂停」态时，侧边栏顶部展示温和松石/琥珀状态卡（绝不用刺眼红框报错），90 秒心跳仅发空数据状态包，成员挂在个人号干活时仍可实时查看全组剩余额度与 5 小时活跃参考。
- **兼容异号家庭组与同号合租的「双模式账号归属锁」**：
  - **每人锁定各自家庭组账号（`per_member_lock`，默认）**：成员首次同步自动锁定当前登录账号指纹，并支持在侧边栏通过二次确认自助换绑（换绑即刻清空暂存队列并从此刻起算）；组长也可在添加/编辑成员时输入邮箱，在浏览器本地计算短指纹预锁该成员（明文邮箱不离开浏览器）。
  - **全组共用同一登录账号（`shared_owner_account`）**：组长在管理台「**设置 → 多账号防串号与套餐档位**」可一键锁定组长当前账号或输入共享邮箱生成全组指纹；生成的单行绑定码附带 `&ah=<20位指纹>`，挂个人号粘贴也会立即进入保护暂停态，100% 防绑错号。
- **官方总池水位防串号三道防线**：
  - 客户端仅在 `ACTIVE_MATCH` 且身份核验通过时拉取和发送 `quotaSnapshots`；
  - 服务端 `ingestHeartbeat` 严格校验 `shared_account_hash` 与权威上报者 `bound_account_hash`（不匹配或 `>=1.6.0` 缺失指纹一律拒收）；
  - 计费引擎 `evaluateQuotaDelta` 新增重置时间大幅倒退（`> 6 小时`）熔断，返回 `isAnchorSwitch: true`，仅更新锚点绝不触发假重置或巨额假扣费。
- **全链路 P0 / P1 / P2 边界加固**：
  - **解绑与换码原子净空**：解绑或更换服务端/绑定码时立即清空 `pendingEvents`、`lastLocalSnapshots` 并全盘快进游标，队列条目附带 `_scopeKey` 发包前二次过滤。
  - **步骤幂等 ID 防碰撞**：精确区分 `step_index: 0` 与缺失 `undefined`，引入零正文特征摘要 `sig8` 与 `lineOffset`，彻底修复会话回退重试同 `step_index` 丢步及无步数记录碰撞 `:s0`。
  - **三端日志目录全覆盖**：新增 `antigravity-cli/brain` 扫描并尊重 `ANTIGRAVITY_GEMINI_DIR` / `ANTIGRAVITY_APP_DATA_DIR`，升级首次挂载新目录时自动将已有历史文件锚定至文件末尾不翻旧账。
  - **`SidecarLease` 单实例租约锁与本地接口限频自愈**：纯文件系统原子租约锁自动回收热重载残留旧实例；宿主模式下连续 3 次本地接口 `401`/`ECONNREFUSED` 且满足 10 分钟冷却时受控重启交由宿主重新注入凭据。
  - **模型归类、`Pro` 独立 `Argon` 池隔离与 `Pro`/`Ultra` 档位自适应**：修复 `neon_xhigh`、`flash_lite`、`Orchestrator (Carbon/Neon/Argon)`、`GPT-OSS 120B` 池归类；依据 `RetrieveUserQuotaSummary` 自动识别 Pro 独立 Argon 桶并排除其混入普通 `gemini` 周池分摊；自动跟随组长 `userTier` 切换 `Pro`（8 万 / 4.5 万）与 `Ultra`（40 万 / 25 万）防背锅与黑洞单位基准。
  - **跨周非整点秒级封账**：周重置时将重置分界点前未结算旧周记录封账为 `-snapshotId`，常规结算传入 `minEventTsMs: prev.captured_at_ms`，杜绝非整 5 分钟重置点（如 `07:02:12Z`）旧账漏入新周。
  - **多设备状态透明与本地控制台补齐**：规则确认版本改为 `MAX` 单调递增；新增匿名随机 `deviceId` 与多设备在线/暂停状态展示；本地控制台补齐 `GET /api/member/me` 并在「装到本机」时浅合并保留已有 `config.json` 账号锁与暂停设置。
- **自动化回归测试**：保留原有 17 组核心测试并新增 12 组红队对抗回归测试（共 **29/29** 全部通过）。
