# v1.2.0 · 规则锁定防暗改、核心计量修复与跨平台安装加固

本次更新综合独立外部安全与可靠性审查结果，重点修复了供应链安装隐患、核心计量与防重复计费漏洞，并加入了绑定码规则锁定与成员变价确认机制。

### 1. 安全与信任机制升级
- **移除未注册包名命令**：全面清除文档与邀请模板中的 `npx agy-market` 命令，所有成员统一通过 GitHub Releases 官方构建包（附 `SHA256SUMS.txt`）或公开源码仓库安装。
- **绑定码锁定初始规则 + 变价需成员确认**：绑定码附带规则版本号、模式与单价摘要；组长修改记账方式或单价时自动写入公开 `rule_changes` 变更日志，未确认新规则的成员不会被按新单价静默扣费，侧边栏顶部将显示新旧规则对比及「确认接受新规则 / 暂不接受并断开」按钮。
- **成员端扣费明细透明化**：按量记账模式下，成员侧边栏可查阅自己最近的分摊扣费明细、充值调整记录与规则变更历史。
- **本地控制台防 CSRF 与脑裂防护**：为本地管理台（`:18945`）与插件独立预览端口（`:18946`）增加随机一次性会话令牌、来源（Origin）和 `Content-Type` 校验；切换为云端同步模式后拦截本地死库心跳并提示同步组长插件地址；`parseInviteCode` 默认强制公网 `https://` 并拦截私网 IP。

### 2. 计量引擎与采集器核心 Bug 修复
- **修复原生 `input_tokens` 归零问题**：对齐 Antigravity `transcript.jsonl` 真实字段语义（`input_tokens` 本身即未缓存新增输入，不再错误减去 `cache_read_tokens`），并纳入产生真实消耗的 `CANCELLED`/`ERROR` 步骤；会话 ID 改为 SHA-256 短哈希脱敏。
- **修复新建对话与子代理首轮漏计**：首次安装记录 `installedAtMs`，安装后新创建的会话一律从 `offset = 0` 读取，不再被误当作安装前历史文件跳过；单行超过 4MB 时流式跳过并推进游标，不再卡死采集器。
- **修复 90 秒心跳重复扣费问题**：在 `usage_reports` 表增加 `settled_snapshot_id` 一次性结算游标，已参与结算的记录立即打标，避免同切片与跨边界后续快照对已停手成员重复扣费。
- **收紧防背锅上限与滚动黑洞检测**：移除原 `10x + 4%` 过大容差，防止未装插件设备的消耗转嫁给轻度在线成员；改用 0.5% 入窗的滚动累计检测，能捕捉 90 秒心跳下的持续慢速未上报掉量，告警发出后清空已消费缓冲。
- **修复跨周重置吞账与周期混算**：组长离线跨官方重置后，新周期已消耗的 `100% - 当前剩余%` 将正确入账到新周期；看板改为严格按当前 `week_bucket` 汇总本周期用量，并新增 **近 5 小时窗口各人活跃参考**。
- **数据库健壮性**：补齐 Cloudflare D1 缺失的 4 个核心索引与 30 天旧快照定期清理；余额变更统一改为原子 SQL 增减；`paused` 状态严格拦截心跳；成员移除改为保留历史总账的软停用归档，并在管理台开放「暂停/恢复」与「重置绑定码」入口。

### 3. 跨平台安装、卸载与网络连通改进
- 修复 `install_macos_linux.sh` 升级覆盖误删已有 `config.json` 的问题，并自动探测本机 `node` 绝对路径写入 `sidecar.json` 解决 macOS GUI 启动找不到 `node` 的问题。
- 在官方构建包内新增一键彻底卸载脚本 `uninstall_windows.cmd` 与 `uninstall_macos_linux.sh`（同步清理插件目录与本地状态文件）。
- 采集器内置零依赖 HTTP CONNECT 代理隧道支持（自动识别 `HTTPS_PROXY`/`HTTP_PROXY` 或侧边栏手填本地代理地址），并支持 `config.json` 修改后自动热重载与 `syncOnce` 并发互斥锁。
- 清理仓库内所有作者本地私有环境残留（无私用 `.exe` 指引、无硬编码 `node.exe` 路径、无私人推送脚本）。
