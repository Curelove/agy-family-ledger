# v1.4.0 · 插件与管理台内置 GitHub Releases 自动检查更新

本次更新为成员端侧边栏插件与组长本地管理台新增内置 GitHub Releases 更新检查功能，方便组员与组长随时获取最新官方构建包，无需手动蹲守仓库页面。

### 新增内容
- **内置 GitHub Releases 更新检查（`update-service.mjs`）**：
  - 优先查询 GitHub Releases API（提取版本号、发布日期、更新摘要与官方构建包 `.zip` 下载链接），当遇到 403/429 频率限制或失败时自动降级读取公开 `releases.atom` 源，免 Token 稳定检查。
  - 复用侧边栏「连接配置」中已填写的本地 HTTP 代理与标准环境变量，零第三方依赖、不读取系统注册表、不扫描本机进程，严格保持原有隐私边界。
  - 内置 6 小时本地缓存与并发去重，支持按版本「忽略此版本」（下个更高版本发布时自动恢复提醒）与开关「启动时静默检查 GitHub 更新」。
- **侧边栏插件与管理台统一更新提醒体验**：
  - 发现新版本时，顶栏展示简洁的 `新版 vX.Y.Z` 胶囊与温和的更新提示卡片；展开底部「版本与更新」面板可查看更新摘要、一键前往 Releases 下载或直接下载官方 ZIP 安装包。
  - 组长本地管理控制台「设置」页同步接入「版本与 GitHub 更新」面板。
- **修复组员侧边栏组长称呼显示问题**：
  - 修正初始化默认组长称呼为「组长」（移除「（我自己）」后缀），并在服务端成员视图与插件侧边栏前端双重兼容历史老库数据，避免普通组员看到「组长（我自己）」以及「组长」标签重复显示的问题。
- **自动化回归**：新增更新检查、Atom 限流降级、6 小时缓存、版本忽略恢复、组长称呼视角隔离与隐私边界端到端回归测试（15/15 通过）。

### 官方构建包校验说明
本版本 `agy-family-ledger-plugin-v1.4.0.zip` 与 `SHA256SUMS.txt` 由 GitHub Actions 直接从公开源码自动构建产出，不含任何个人网址或成员凭证；覆盖运行安装脚本会自动保留已有绑定配置与代理设置。
