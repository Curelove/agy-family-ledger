# v1.1.0 · 纯净官方源分发与熟人共享看板改版

本次更新取消了由组长私下生成并发送 `.zip` 压缩包的安装方式，改为「成员统一从 GitHub 官方公开源安装插件 + 粘贴单行纯文本绑定码连接」，并大幅精简了日常使用界面。

## 主要变更

- **取消私人安装包，改为单行纯文本绑定码**
  - 本页面下方的 `agy-family-ledger-plugin-v1.1.0.zip` 由 GitHub Actions 直接从公开源码自动构建，并附带 `SHA256SUMS.txt` 校验值；已安装 `agy-market` 的用户也可直接运行 `npx agy-market add https://github.com/Curelove/agy-family-ledger/tree/main/member-plugin` 安装。
  - 组长在控制台点击「邀请绑定」后，只需向朋友发送一行纯文本绑定码（格式为 `https://域名#agf_xxxx`），全程不再传输任何可执行脚本或私人打包文件。
- **默认采用「纯看板模式」，按需开启记账**
  - 默认界面只展示 Gemini 4 与 Claude 3P 的全组剩余额度，以及各成员近 7 天的用量占比，隐藏了余额、单价和充值表格。
  - 如确实需要记录预存余额与按比例扣费，可在控制台「设置」中切换到「按量记账模式」。
- **新增组内成员占比透明展示**
  - 成员侧边栏新增「组内成员近 7 天占比」列表（仅展示称呼、在线状态与用量百分比，不含任何凭证或金额），方便熟人之间互相查看当前使用情况、错峰跑大任务；组长也可在设置中随时关闭该列表。
- **合并重复导航与术语清理**
  - 管理控制台合并为「看板总览 · 异常记录 · 设置」三个标签页，去掉了重复的成员列表与难懂的自定义词汇。

## 校验方式

下载 `agy-family-ledger-plugin-v1.1.0.zip` 后，可在终端校验文件指纹是否与 `SHA256SUMS.txt` 一致：

```powershell
# Windows PowerShell
Get-FileHash .\agy-family-ledger-plugin-v1.1.0.zip -Algorithm SHA256
```

```bash
# macOS / Linux
shasum -a 256 agy-family-ledger-plugin-v1.1.0.zip
```
